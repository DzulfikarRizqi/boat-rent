# kapalin
Kapalin merupakan aplikasi dalam proyek junior TIF untuk rental berbagai macam kendaraan laut, seperti perahu, speedboat, kapal, yacht di berbagai pulau.
Kapalin membantu pengguna dalam memesan kendaraan laut pada lokasi liburannya.
